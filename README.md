# EbloChat

Twitch chat inside Minecraft (Fabric, 26.1.2) with Chatterino-style features: channel tabs, mentions, badges, chat history, moderation events and user cards.

**Download:** https://modrinth.com/mod/eblochat 

## Build
    ./gradlew build

Requires Java 25. The jar appears in `build/libs`.
